# 公共まとめ(-夏休み)

## 日本国憲法と大日本帝国憲法の違い

日本国憲法は戦争へつながった*大日本帝国憲法の反省*を元に作成。

* **1946年 11月 3日 (文化の日)** 公布

* **1947年 5月 3日 (憲法記念日)** 施行

| 権利 | 日本国憲法 | 該当する条番号 | 大日本帝国憲法 |
| :--- | :--- | :--- | :--- |
| **主権** | 国民 | 全文、1条 | 天皇主権 |
| **天皇** | 日本国民総意に基づく象徴 | 1条 | 国家元首 |
| **戦争** | 平和主義 | 9条 | 天皇に総帥権<br> 国民に兵役の義務 |
| **国民の権利** | 基本的人権は永久不可侵 | 11条、97条 | 臣民の権利(法律で定められる。) |
| **国会** | 国権唯一の最高機関 | 41条ほか | 天皇の下にある |
| **内閣** | 行政権の最高機関<br>国会に対して責任を追う | 65条ほか | 天皇を助ける機関<br>天皇に対して責任を追う |
| **裁判** | 独立した司法権による裁判 | 76条ほか | 天皇の名による裁判 |

* 国民主権のもと**行政権**・**立法権**・**司法権**の**三権分立**によって社会が成り立っている。

* 憲法改正には国会での2/3の支持、国民投票での過半数の支持がないといけない。
  日本国憲法はこの性質から、**硬性憲法**ともいわれる。

## 基本的人権
* 基本的人権は国家と国民の間の権利を定めたもの。
  **私法**(民法など)などには*間接適用される。* (**私法自治の原則** - *三菱樹脂訴訟*)

* 基本的人権は**公共の福祉**とのバランスをとる。

*  外国人には一部の基本的人権が制限されている。

### 自由権
国家からの自由とも言われる。以下の3つに分類される。

* 精神的自由
  - 思想・良心の自由、信教の自由、学問の自由など、個人の内面に係る自由
  - 表現の自由(公共の福祉に反さない限りのもの)

* 身体の自由
  - 奴隷的拘束および苦役からの自由
  - 刑事訴訟法などで*法定手続きの保証*がされている (**罪刑法定主義**)
  - 冤罪を防ぐための黙秘権

* 経済的自由
  -  自立した個人として生計を営むための権利
  -  居住・移転および職業選択の自由、財産権の保障
 
### 法の下の平等
* 家族生活において個人の尊厳と両性の平等
* 選挙権の平等
* 教育の機会均等
が憲法に明記されている。

また、差別解消のため、以下の法・訴訟が存在する。
* **障害者差別解消法**
* **女子差別撤廃条約** - **男女雇用機会均等法**
* **盗賊殺人重罰規定訴訟**
* **DV防止法**
* **女性再婚規期間定訴訟**(民法の規定)

### 社会権
社会権は生存の保障や福祉の実現を国家に求める権利
* **生存権** - 社会福祉、社会保障など
* **等しく教育を受ける権利** - 義務教育の無償化
* **勤労の権利**
* **労働三権** - 団体権・団体交渉権・団体行動権(公務員を除く)

### 新しい人権
* **環境権** - より良い生活環境を享受する権利 大阪国際空港公害訴訟など
* **プライバシー権** - 幸福追求権の一つ **個人情報保護法**など
* **自己決定権** - 自己の生き方を他者の介入なしに決定する権利 *インフォームド・コンセント*など

### 基本的人権を確保するための権利
* **参政権** - 国民固有の権利として保障 選挙権、住民投票、最高裁判所裁判官国民審査など
* **国務請求権** - 国家賠償請求訴訟(国家賠償法に基づく)など
    - 請願権
    - 裁判を受ける権利
    - 刑事補償請求権
    - 国家賠償請求権
